글자수 세기

한글은 1자, 공백·줄 수, UTF-8 바이트와 EUC-KR 추정 바이트를 셉니다. 입력은 이 기기에만 남습니다.

브라우저에서만 계산

입력값은 서버로 전송되지 않습니다. 결과를 저장하거나 공유하려면 화면을 직접 남겨 두세요.

제휴 안내 · 자리만 확보

관련 상품이나 서비스 소개를 넣을 칸입니다. 지금은 제휴 링크를 연결하지 않았습니다.

생활계산서 · 계산 결과는 참고용입니다. 고지서, 홈택스, 근로계약, 대출 약정과 다를 수 있습니다.

2026년 공개 요율을 반영했습니다. 요율이 바뀌면 고지서나 공식 안내가 우선합니다. 개인정보는 서버에 보내지 않고 브라우저에서만 계산합니다.

GitHub Pages 배포용 정적 사이트 · 저장소는 아직 만들지 않았습니다.
